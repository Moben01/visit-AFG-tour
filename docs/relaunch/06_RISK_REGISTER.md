## Release gates

The public relaunch should not proceed until all of the following have evidence:

1. R-01 through R-08, R-22 through R-25, and R-28 are mitigated and independently tested.
2. A migration baseline can create an empty schema and safely reconcile a production-like copy without data loss.
3. Direct anonymous requests to every private document path fail, while authorized roles can access only their permitted objects.
4. Payment mismatch, duplicate webhook, and replay cases cannot mark a booking paid.
5. Every public claim/contact/tour/price/review is approved and backed by real capability/data.
6. Canonical routes, redirects, sitemap/robots/noindex and rendered metadata pass automated checks.
7. A versioned deployment runbook, dependency set, backup/restore and rollback exercise exist.
8. The full test suite passes on PostgreSQL and critical browser journeys are manually verified.
